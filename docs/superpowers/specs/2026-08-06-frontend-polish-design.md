# 前端精致化设计 — cin's blog

> 日期：2026-08-06
> 范围：cjh1230.github.io（Astro 4 + Tailwind + React islands）

## 背景

个人技术博客（嵌入式 / CV / 机器人），基于 Astro 构建，功能完整（搜索、评论、友链、主题切换、8 种强调色、CSS 动画库、ViewTransitions）。

**目标**：保留现有奶油色 + comimi 弹性动画风格，做系统性精致化。三个方向：视觉设计、动效体验、性能。

**用户痛点**（多选）：

1. 首页/卡片不够精致
2. 配色/主题不和谐
3. 动效不协调

**已确认的方向决策**：

- 保留现风格，不做方向性重设计（排除现代简约 / 科技极客 / 杂志编辑风）
- 方案 A：设计系统驱动（先统一色彩 + 动效系统，再应用到组件，最后性能）

## 现状诊断

| 问题       | 根因                                                                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 配色不稳定 | `AccentColorInjector` 每次页面加载 `Math.random()` 选 1/8 强调色，刷新/翻页即变                                                             |
| 基底打架   | `bg-root` 用 `#fafafa` 混强调色 5%，`bg-primary` 固定 `#fffff0`，两套基底不一致                                                             |
| 8 色不和谐 | 色相跨度大（红/蓝/橙/青/紫/绿），明暗变体色相完全不同                                                                                       |
| 动效散乱   | 弹性曲线与线性曲线混用；Hero 同屏 3 种入场动画；卡片既有加载 stagger 又有滚动 reveal                                                        |
| 卡片简陋   | PostCard 纯文本行，无封面/日期 badge/标签 chips 等质感元素                                                                                  |
| 性能基线   | JS 647K（Waline 164K + 首页 132K + 版权 96K + motion 56K）；CSS 116K；KaTeX 字体 ~120K 全局随行；图片 8.8M / 40 张 PNG；单页 HTML 最大 208K |

## 设计内容

### 1. 色彩系统

**① 强调色机制 → 会话固定**

- 首次访问用 `crypto.getRandomValues` 选色，写入 `localStorage`，同浏览器内所有页面/刷新保持一致
- 页脚提供手动切换入口（8 色小圆点选择器，不占用头部空间）
- 重写 `AccentColorInjector` 逻辑（从随机改为读缓存），保留明暗两套强调色变体

**② 统一语义色 token**（修复基底打架）

| Token            | 亮色                   | 暗色                | 用途            |
| ---------------- | ---------------------- | ------------------- | --------------- |
| `bg-root`        | `#faf7ef`              | `#10101d`           | 页面最底        |
| `bg-primary`     | `#fffdf5`              | `#171724`           | 主体内容        |
| `bg-secondary`   | `#f4efe0`              | `#23233a`           | 卡片/代码块     |
| `bg-surface`     | `rgba(255,255,255,.8)` | `rgba(30,30,50,.8)` | 浮层/头部毛玻璃 |
| `text-primary`   | `#2b2b3a`              | `#e8e8f2`           | 正文            |
| `text-secondary` | `#6b6b78`              | `#a8a8c0`           | 次要文字        |
| `border`         | `#e6dfc8`              | `#3a3a5e`           | 分隔线/边框     |

- token 写入 `config.json` 的 `color` 字段，由 `AccentColorInjector` 生成 CSS 变量（沿用现有机制）
- 强调色只用于交互元素（链接、激活导航、按钮、section 圆点、进度条）；大面积只用 5-10% tint

**③ 保留**：奶油色亮色 / 深靛蓝暗色的整体性格，8 色强调色的可玩性

### 2. 动效语言 + 组件精致化

**动效规范（每个交互只保留一种反馈）**

| 场景           | 统一为                         | easing            |
| -------------- | ------------------------------ | ----------------- |
| 进入视口       | `.reveal` 淡入上滑，只触发一次 | `--ease-out-expo` |
| 首屏入场       | 保留定制但统一节奏             | 小元素 `--spring` |
| 卡片悬浮       | 上浮 `-3px` + 阴影加深         | `--ease-out`      |
| 图标/箭头/徽章 | 弹性微动效                     | `--spring`        |
| 点击反馈       | 收缩回弹 `pop-click`           | `--spring`        |

- 移除卡片"加载时 stagger + 滚动 reveal"双重动画，统一为滚动 reveal 一次
- `prefers-reduced-motion` 支持保留

**PostCard 重设计**

- 封面：固定宽高比（4:3）小封面，hover 轻微放大 + 圆角
- 标题：hover 时转 accent 色
- 摘要：最多 2-3 行截断
- 底部 meta：日期 + 阅读时长小 badge；标签彩色 chips
- hover：accent 左细条 + 上浮 + 背景 tint（克制组合）
- 置顶推针保留

**Hero / SectionBlock / 侧边栏**

- Hero：`cin` 字符弹跳保留；副标题统一 fade-up 节奏；头像加 accent 光圈 + 悬浮微动效
- SectionBlock：accent 圆点保留，标题行加渐隐装饰线
- 侧边栏标签 chips 化，分类带计数

### 3. 性能

| #   | 优化项         | 做法                                                                                       |
| --- | -------------- | ------------------------------------------------------------------------------------------ |
| 1   | 图片轻量处理   | 不动格式，仅补 `loading="lazy"` + `decoding="async"` + 宽高属性（通过 `rehypeImage` 插件） |
| 2   | KaTeX 按需加载 | 构建时检测文章是否含公式，仅该类文章引入 katex CSS（当前全局引入）                         |
| 3   | 字体优化       | Atkinson 转 woff2 + 更新 @font-face（swap 保留）；中文确认走系统回退                       |
| 4   | JS 分包核查    | 核查首页 bundle 132K / 版权 96K，去除冗余；Waline 确认懒加载                               |
| 5   | 清理           | 找出 animations.css 未引用类并移除；未使用依赖检查                                         |

**验证**：优化前后对比 dist 体积 + 本地预览测资源字节数。

## 成功标准

- 任意访问会话内，强调色在页面间稳定；手动可切换
- 明暗主题下背景/文字/边框协调无打架
- 首页卡片与 Hero 视觉精致度明显提升（对照前后截图）
- 动效去重后无双重动画，滚动 reveal 统一
- 无公式页面不再加载 KaTeX 资源；字体为 woff2
- dist 体积 / 关键资源字节数较基线下降（不含图片格式转换）

## 范围外（Non-goals）

- ❌ 图片转 WebP / AVIF（用户明确排除）
- ❌ 替换 framer-motion（集成太深，风险大，仅做分包核查）
- ❌ 更换整体设计方向（保留现风格）
- ❌ 文章阅读页排版重构（未列为痛点）
- ❌ 无障碍专项（未选中方向）
